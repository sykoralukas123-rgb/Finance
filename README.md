# SorareBuddy Clone — Sorare companion (demo)

Unofficial, fan-made functional rebuild of the Sorare companion app
[SorareBuddy](https://sorarebuddy.com) — built from scratch with original code and
**fully simulated demo data**. Not affiliated with Sorare or SorareBuddy.

## Features

- **Live** — your card collection scored in real time during a simulated gameweek,
  with a live match list and a notification feed (goals, assists, cards)
- **Fixtures** — full match calendar, filterable by competition
- **Market** — floor prices across all rarities (Limited / Rare / Super Rare / Unique),
  30-day price sparklines, 7-day trend, search / position filter / sorting
- **Lineup Builder** — build a 5-card lineup (GK / DEF / MID / FWD / Extra), pick a
  captain (+20 %), projected score, saved to `localStorage`, demo "Send to Sorare"
- **Leaderboards** — divisions with rewards, gameweek streaks, your rank highlighted
- **Gallery** — full card collection with rarity filters, floor value and P/L per card
- **Player detail** — season stats (xG, xA, shots on target, duels, pass accuracy…),
  last-15 SO5 score chart and 30-day price chart

Live scores, events and prices are generated by a small simulation engine
(`src/buddy/engine/useLiveGameweek.ts`). A real deployment would swap that hook for
the Sorare GraphQL API (OAuth 2.0) without changing the UI.

Built with React 19 + TypeScript + Vite + Tailwind CSS + Recharts.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # serve the production build
```

## Where things live

- `src/buddy/BuddyApp.tsx` — app shell (sidebar navigation, header)
- `src/buddy/pages/` — Live, Fixtures, Market, Builder, Leaderboard, Gallery
- `src/buddy/components/` — card visual, player modal, shared UI, rarity helpers
- `src/buddy/data/` — demo players, collection, fixtures, leaderboards
- `src/buddy/engine/useLiveGameweek.ts` — live gameweek simulation

*Note: the earlier ValueXI landing page (`src/landing/`) and the personal finance
tracker (`src/pages/`, `src/components/`) still live in the repo on their own
branches; this branch mounts the SorareBuddy clone.*
